# Day39 - Smart Door Lock System

## Objective
To design a secure door access system using password authentication.

## Platform
- Wokwi Simulation
- Arduino UNO

## Components Used
- Keypad
- Servo Motor
- LCD (I2C)
- LED
- Buzzer

## Working Principle
1. User enters password
2. System verifies input
3. If correct:
   - Door unlocks
4. If wrong:
   - Alert triggered
