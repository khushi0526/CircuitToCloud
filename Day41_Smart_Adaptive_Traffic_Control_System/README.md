# Day41 - Smart Adaptive Traffic Control System

## Objective
To dynamically control traffic signals based on vehicle density.

## Platform
- Wokwi Simulation
- Arduino UNO

## Components Used
- Ultrasonic Sensors (2)
- LEDs (Traffic signals)
- Buzzer
- Push Button

## Features
- Traffic density detection
- Dynamic signal timing
- Emergency override system

## Working Principle
1. Sensors detect traffic density
2. More vehicles → longer green signal
3. Emergency button overrides system
