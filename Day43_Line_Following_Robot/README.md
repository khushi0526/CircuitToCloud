# Day43 - Line Following Robot

## Objective
To design a robot that follows a path using sensor-based control.

## Platform
- Wokwi Simulation
- Arduino UNO

## Components Used
- IR Sensors (2)
- Motor simulation

## Working Principle
- Sensors detect line
- Robot adjusts direction accordingly
