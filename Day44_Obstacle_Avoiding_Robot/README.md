# Day44 - Obstacle Avoiding Robot

## Objective
To design a robot that detects obstacles and changes direction automatically.

## Platform
- Wokwi Simulation
- Arduino UNO

## Components Used
- Ultrasonic Sensor
- Servo Motors (2)
- LED
- Buzzer

## Working Principle
1. Ultrasonic sensor measures distance
2. If no obstacle → robot moves forward
3. If obstacle detected:
   - Stops
   - Turns direction
   - Continues movement
