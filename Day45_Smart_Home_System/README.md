# Day45 - Smart Home System (Core)

## Objective
To build a multi-room smart home system with automation and security.

## Platform
- Wokwi Simulation
- Arduino UNO

## Modules
- Living Room (Light + Fan)
- Bedroom (Auto light)
- Security (Motion detection)

## Components Used
- LED
- Servo Motor
- Potentiometer
- PIR Sensor
- Buzzer

## Working Principle
- Living room devices always ON
- Bedroom light adjusts based on light level
- Motion triggers alarm system
