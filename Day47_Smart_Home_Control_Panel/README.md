# Day47 - Smart Home Control Panel

## Objective
To build a complete smart home system with UI and control modes.

## Features
- Auto & Manual modes
- LCD display interface
- Separate control buttons
- Motion detection system

## Components
- LCD (I2C)
- LED
- Servo Motor
- PIR Sensor
- Buzzer
- Push Buttons
