# Day49 - UART Communication System

## Objective
To simulate master-slave communication using UART.

## Features
- Command-based control
- Serial communication
- Device control via messages

## Components
- LED
- Servo Motor

## Simulation Link
https://wokwi.com/projects/462839992419337217

## Commands
- 1 → LED ON
- 0 → LED OFF
- 2 → FAN ON
- 3 → FAN OFF

- UART communication
- Embedded protocols
- Master-slave systems
